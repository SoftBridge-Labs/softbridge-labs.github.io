AiDroid

The Professional AI Chat Interface

AiDroid is a modern, high-performance local AI assistant for Android, designed to provide seamless offline intelligence directly on your device. Built with the Flutter SDK, it combines a sophisticated modular architecture with a responsive, glassmorphic UI to deliver a premium user experience.

Key Features

visibility_lock

Offline Chat & Vision

Leveraging local processing for privacy and speed, AiDroid offers robust chat capabilities and vision features without requiring an active internet connection.

mic

Audio & Speech

Includes advanced audio tools such as an "Audio Scribe" and speech-to-text functionality for hands-free interaction.

terminal

Intelligent Text

Features a specialized "Prompt Lab" for refining AI interactions and utilizes OCR via Google ML Kit for advanced text recognition.

memory

Model Management

A dedicated model manager allows users to control their local AI environment efficiently and with total precision.

Technical Highlights

Cross-Platform Core

Built using Flutter and Dart (v3.10.8+), ensuring a smooth, native feel on Android devices.

Clean Architecture

Logic organized into distinct features, utilizing Riverpod for robust and scalable state management.

Enhanced Power

Optimized with Dio, LlamaDart for local execution, and Glassmorphism for modern aesthetics.

Privacy-First

By prioritizing local execution, AiDroid ensures all user data remains secure on the device.

AiDroid represents the next generation of mobile assistants, bringing the power of large language models to your pocket with a focus on privacy, speed, and versatility.
