# WebMCP Tools

Provides client-side capabilities to fetch products, developer utilities, and career listings directly in the browser using the WebMCP protocol.

## Description

This skill enables AI agents to query the SoftBridge Labs database for products, developer utilities, and active career openings via WebMCP.

## Actions

### get_products_list
Fetches the current collection of active products.

### get_devtools_list
Fetches the current list of developer tools.

### get_job_openings
Fetches active job listings.
